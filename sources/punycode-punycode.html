Punycode-конвертер

Punycode — метод для преобразования национализированных доменных имён (.РФ, .ДЕТИ, .ҚАЗ) из Unicode в ACE (ASCII Compatible Encoding) для корректного написания и отображения домена в адресной строке. Возможно прямое и обратное преобразование.



  • Проверить DNS-записи домена

  • Узнать свой IP-адрес

  • Проверить порт на доступность

  • Проверка скорости интернета

Для чего нужен Punycode?
Исторически при создании интернета рабочим языком был английский, поэтому изначально домены могли содержать только буквы латинского алфавита, цифры или тире. С появлением национализированных доменов (.РФ, .ҚАЗ и других) появился метод Punycode для перевода символов национального алфавита на латиницу. Например, домен РОЗОЧКИ.РФ в формате Punycode будет выглядеть как XN--G1ACFOBJ6C.XN--P1AI.
Что такое IDN-домены?
IDN-домены (Internationalized Domain Names) — доменные имена, содержащие символы национальных алфавитов, например, ПРЕЗИДЕНТ.РФ.
Как домен XN--C1AD6A.XN--P1AI отображается в адресной строке браузера?
При указании IDN-домена в адресной строке браузер автоматически преобразует его в пуникод, чтобы открыть сайт. Вставив в адресную строку домен XN--C1AD6A.XN--P1AI, вы автоматически окажетесь на сайте РЕГ.РФ.
Punycode конвертер подходит для любых национальных IDN-доменов?
Да, его можно использовать не только для перевода домена .РФ в Punycode, но и для конвертирования любых доменов, которые содержат буквы национальных алфавитов.
