# Sources

Immutable capture layer for the LLM wiki. Content here is **outside** the Obsidian vault (`wiki/`).

## Policy

- **URL bookmarks and long pastes** — written here on first ingest, then treated as read-only.
- **Short notes** — live only under `wiki/`; no file is created here.
- **Corrections** — the `/kb` skill MAY edit an existing capture body only when the user explicitly asks to fix a capture error. Corrections are noted in `wiki/log.md`.

## Layout

Files are organized organically as content grows (no fixed bucket list at init). Filenames are kebab-case slugs generated by the TypeScript slug CLI in `scripts/kb/` (added in a later init stage).

## Why separate from `wiki/`

Captures stay outside the Obsidian graph so derived wiki pages remain browsable without mixing raw dumps into the vault. Derived pages under `wiki/` link back to their capture when applicable.
