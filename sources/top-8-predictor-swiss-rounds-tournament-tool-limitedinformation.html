Welcome to the Top 8 predictor!

Enter the number of players and rounds in the "Calculation Inputs" box, and click submit.
Running it with include draws (default) checked, it will try to figure out which players can draw into the top 8.
Running it without intentional draws is for scenarios like MTGO where there are no intentional draws.
In both ways if a player gets paired down, the player with the highest score wins.
Similarly, a "bye" is always given to the player with the lowest score, if there is an odd number of players.

If you think the results are incorrect for some reason, please send me a message
at playordraw (at) gmail (dot) com with as much information as possible.
