# Manual invocation

**`/tacos-project-overview`** or natural language (“update the project overview”, “add X to the getting started section”, “remove the beta note from Installation”).

## User scope (required)

The user SHOULD specify what to **add**, **update**, or **remove** (sections, bullets, or topics). If the message is vague, ask once:

> Which parts of `{path}` should I add, update, or remove?

Worked examples: skill **Manual scope** table in `SKILL.md`.
