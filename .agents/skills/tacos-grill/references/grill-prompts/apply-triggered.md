# Apply triggered grill

Run **before each** pending implementation checkbox when a signal in [triggered-grill.md](../triggered-grill.md) matches and the matching `grill.triggers.*` key is `true`. Short parent interview (1–3 questions). Focus when implementation is blocked or would change requirements:

- What is ambiguous about the current task?
- What product or policy decision is needed?
- Does implementation reveal a spec or design gap?
- Should artifacts be updated before continuing?

Do not block mechanical work when no signal fires.
