# Неуспешные платежи — Прием платежей по API ЮKassa

https://yookassa.ru/developers/payment-acceptance/after-the-payment/declined-payments

## Summary

Если в процессе платежа что-то пошло не так, ЮKassa сообщит вам, кто инициатор отмены, и по какой причине не прошел платеж. Приём платежей для интернет-магазинов, с банковских карт, через SberPay, электронными деньгами и другими способами. Документация API — руководство по интеграции с ЮKassa для разработчиков.
