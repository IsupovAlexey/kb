# Отзывы оформляются по почтовым сделкам вне своего города. Это может быть продажа

Отзывы оформляются по почтовым сделкам вне своего города. Это может быть продажа, покупка (в том числе с аукционов), или обмен.

Раз ссылку на аукционы вы уже узнаете, вот где еще можно продать/купить/обменять карты и/или другие магические товары:

https://topdeck.ru/forums/forum/144-продажа-карт/ (поиск: https://topdeck.ru/apps/toptrade/singles/search)

https://topdeck.ru/forums/forum/145-покупка-и-обмен/

https://topdeck.ru/apps/toptrade/store (строго не для синглов)

Для всего этого нет никаких ограничений по отзывам.

витрина магазина — TOPTrade: https://topdeck.ru/apps/toptrade/store

синглы/поиск — TOPTrade: https://topdeck.ru/apps/toptrade/singles/search
